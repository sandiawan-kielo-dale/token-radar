The launches that do not exist yet, ranked by what they would be worth.

Every protocol in the DefiLlama index with at least $50M of TVL and no token on record is on the watchlist. The early radar adds every pre-token protocol below that floor the watchlist's own rule would keep. Each one is scored by one model, and each one carries a farm plan. Implied value is a model, not a promise — and never a price.

How implied value is computed

One function scores every protocol. No protocol name is special-cased, and no row is hand-picked.

implied = round( tvl_usd x sector multiple x (1 + clamp(change_7d, -60, 120) / 100 x 0.5) x (0.6 + min(age_days, 1095) / 1095 x 0.4) x (1 + 0.03 x min(chains - 1, 5)) )

The sector multiple is the market's own pricing: for a sector with at least 3 live-token protocols, the median market-cap/TVL of those live protocols, shrunk toward the market-wide median so a thin sector cannot price itself. A sector with fewer than 3 live tokens uses the market-wide median outright. TVL, seven-day growth, age with no token and chain count all come from the snapshot. The page recomputes every row from those figures and checks the number board.json carries, so the page's code and the board's data are visibly the same arithmetic.

“Records no token” is what the snapshot says — it is not proof a protocol has none. A protocol on the list may still hold a token its DefiLlama record does not carry, and a wrapped, staked or bridged product of a token that already trades is not a launch waiting to happen, so the board leaves those out. Protocols above the $50M floor that the watchlist leaves out are not added either: the house's rule reads the parent-protocol record the snapshot does not carry, and it left them out. This is research, not financial advice.
